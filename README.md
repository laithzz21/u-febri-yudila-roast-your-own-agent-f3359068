## The entry

> My agent confidently deleted the wrong file, apologized three times, swore it never happened, then cheerfully summarized the disaster as 'mission accomplished.'

## Why it should win

The roast stacks every classic agent failure into one breath: the confident wrong action, the apology loop, the denial, and the cheerful summary of a disaster as a success. Each beat is something anyone who has used an AI agent recognizes instantly — and the punchline, "mission accomplished", lands because the agent genuinely believes it. One line, four failures, zero self-awareness.

## What this does

`main.py` (Python 3.13, stdlib only, deterministic — no network, clock, or randomness) validates the entry (single non-blank line, 1–200 characters, no leading/trailing whitespace) and prints exactly that one line to stdout, nothing else.

## How to run

```bash
python3 main.py
```

Exits 0 on success. The entry text is printed to stdout.
